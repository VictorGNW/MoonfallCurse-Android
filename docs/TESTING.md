# Estratégia de testes eficientes

1. Revisão estática e testes unitários específicos.
2. Compilação incremental somente das partes alteradas.
3. Smoke test de inicialização/pausa/retomada quando aplicável, sem gameplay autônomo.
4. Benchmark controlado apenas com hipótese de performance e cenário reproduzível autorizado.
5. Registrar dispositivo, driver, build, resolução, preset, P50/P95/P99, crashes, RAM, energia e limitações.

Nunca dizer que todas as GPUs estão corrigidas com teste de uma única GPU. Não repetir testes idênticos sem nova hipótese.

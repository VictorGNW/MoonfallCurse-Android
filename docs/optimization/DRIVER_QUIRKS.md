# Registro de quirks de drivers

Para cada workaround registrar: GPU e driver, Android, Vulkan, sintoma, evidência, condição de ativação, efeito secundário, responsável e prazo de revisão.

Política:
- Preferir correção genérica quando viável.
- Não desativar recurso globalmente por bug isolado.
- Não marcar drivers como afetados sem logs/reprodução.
- Fallback seguro deve preservar compatibilidade de GPUs não afetadas.
- Remover workarounds após correção comprovada em nova versão de driver.

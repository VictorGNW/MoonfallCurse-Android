# Migração de configurações

- Versionar schema e validar valores antes de aplicá-los à GPU.
- Ignorar chaves desconhecidas com aviso, sem invalidar tudo.
- Evitar configs de outro título/preset incompatíveis.
- Após crash de inicialização, oferecer reset somente das opções gráficas problemáticas.
- Preservar saves, assinatura, controle touch e preferências não relacionadas.
- Escrever arquivos por substituição atômica quando possível.

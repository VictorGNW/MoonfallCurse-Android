# Integridade de saves

- Nunca eliminar, mover ou sobrescrever saves sem autorização.
- Preservar paths Android e compatibilidade entre versões.
- Preferir gravação atômica e backup temporário quando apropriado.
- Separar configuração gráfica e save para que recuperação de crash não apague progresso.
- Não usar saves pessoais em logs ou repositório.
- Validar mudanças de migração com testes determinísticos, não gameplay.

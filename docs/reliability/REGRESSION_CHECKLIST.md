# Checklist mínimo de regressão

- [ ] Compilação/validação incremental adequada concluída ou explicitamente dispensada
- [ ] Inicialização sem nova falha conhecida
- [ ] Touch, áudio, SDL e Forge preservados
- [ ] Cache e configuração preservados/migrados com segurança
- [ ] Saves e assinatura Android não afetados
- [ ] Impacto Mali/Adreno/Xclipse avaliado, inclusive não testados
- [ ] P95/P99, latência, RAM e bateria considerados se relevante
- [ ] Limitações, resultados e arquivos alterados documentados
- [ ] Nenhum gameplay autônomo
